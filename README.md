# ЭргоКлавиатура

Эргономичный слой поверх **ЙЦУКЕН** и **QWERTY** для Android 14+.
Клавиатура прощает спешку, а не переучивает: большой хитбокс, локальный словарь,
навигационные свайпы и безлимитный буфер обмена. Без облака, аккаунтов и ИИ.

## Что внутри

- **Хитбокс 130% при визуале 100%.** Зона нажатия каждой клавиши шире рисунка;
  при промахе между клавишами выбирается ближайшая по центру.
- **ЙЦУКЕН + QWERTY.** Переключение клавишей `РУ/EN`. Символьная страница `?123`.
- **Локальный словарь.** База в `assets/ru.txt` и `assets/en.txt` (частотный порядок),
  плюс свои слова: ники, имена, сленг, мат. Всё лежит в `files/dictionary_user.txt`.
- **Мягкая автозамена.** Исправляет только очевидную опечатку (расстояние 1),
  не трогает слова с заглавной буквы и всё, что есть в словаре.
- **Свайпы только для навигации.**
  - свайп влево/вправо по пробелу — курсор по символам (с подсказкой «← 3»);
  - свайп влево по `⌫` — удалить слово;
  - свайпы по буквам ничего не вводят.
- **Безлимитный буфер обмена.** История хранится локально в `files/clipboard.json`,
  кнопка `📋` открывает панель. Не 20 последних системных записей, а вся история.
- **Режим одной руки.** Клавиатура прижимается влево или вправо и занимает 86% ширины.
- **Долгое нажатие `е` → `ё`, `ь` → `ъ`.**
- **Material 3 Expressive.** Крупные радиусы, тональные поверхности, динамические
  цвета системы (Material You), пружинные акценты, крупная типографика.
- **Виброотклик** с настройкой, высота клавиатуры 34–58%, размер хитбокса 100–150%.

## Структура

```
app/src/main/
  java/com/ergokeys/ime/
    ErgoImeService.kt    — IME, ввод, автозамена, буфер, панель
    KeyboardView.kt      — отрисовка и тач-логика (Canvas, без лишних View)
    KeyboardLayouts.kt   — раскладки и веса клавиш
    Dictionary.kt        — локальный словарь и подсказки
    ClipboardStore.kt    — безлимитная история буфера
    SharedData.kt        — общий словарь и буфер для клавиатуры и настроек
    ErgoPrefs.kt         — настройки в SharedPreferences
    SettingsActivity.kt  — настройки на Compose Material 3
  assets/ru.txt, en.txt  — базовая база слов
  res/xml/method.xml     — регистрация IME и подтипов
```

Отрисовка клавиатуры сделана на `Canvas` одним View: ~40 клавиш перерисовываются
без создания View-иерархии, геометрия пересчитывается только при изменении размера
или настроек. Подсказки ищутся бинарным поиском по отсортированному массиву.

## Сборка

На телефоне APK собрать нельзя: нужны JDK 17 и Android SDK. Варианты:

### Android Studio (проще всего)

1. Откройте папку `ErgoKeys` в Android Studio (Ladybug или новее).
2. Дождитесь синхронизации Gradle.
3. `Build → Build App Bundle(s) / APK(s) → Build APK(s)`.
4. APK: `app/build/outputs/apk/debug/app-debug.apk`.

Либо из терминала:

```bash
gradle :app:assembleDebug
```

(или `./gradlew`, если сгенерируете wrapper в Android Studio).

### AndroidIDE на телефоне (без Linux/Termux)

Можно поставить **AndroidIDE** — это обычное Android-приложение со встроенными JDK и
Android SDK. Откройте в нём папку `ErgoKeys`, дождитесь синхронизации Gradle и соберите
`app:assembleDebug`. Требуется несколько гигабайт свободной памяти.

### GitHub Actions (без ПК)

1. Залейте папку в репозиторий GitHub.
2. Откройте вкладку **Actions → Build APK → Run workflow**.
3. Скачайте артефакт `ErgoKeys-debug` — внутри готовый APK.

Workflow уже лежит в `.github/workflows/build.yml`.

## Установка и включение

1. Установите APK (разрешите установку из неизвестного источника для файлового
   менеджера).
2. Откройте «ЭргоКлавиатура» → **Включить** → включите клавиатуру в списке.
3. Вернитесь и нажмите **Выбрать** → выберите «ЭргоКлавиатура».
4. На HyperOS/Poco: *Настройки → Дополнительные настройки → Языки и ввод →
   Клавиатуры* (путь может немного отличаться). Если клавиатура не появляется,
   переключите её через значок клавиатуры в панели навигации.

> На HyperOS иногда нужно отключить оптимизацию батареи для приложения, чтобы
> система не выгружала IME. Приложение не просит интернет-разрешений.

## Свои слова

- Через настройки: «Локальный словарь» → добавить слово.
- Или отредактируйте `app/src/main/assets/ru.txt` / `en.txt` и пересоберите.
  Формат: одно слово в строке, порядок = частота (чем выше, тем чаще в подсказках).

## Ограничения

- Словарь базовый (сотни слов), а не гигабайтный. Он специально маленький и
  предсказуемый; пополняется своими словами и выученной частотой.
- Свайп-набор (glide typing) намеренно отсутствует: свайпы оставлены навигации.
- Курсор двигается аппаратными `DPAD_LEFT/RIGHT` через `InputConnection`;
  редкие поля ввода могут игнорировать такие события.
- Панель буфера показывает последние 300 записей для скорости, но хранит все.
- Приложение не собирает и не отправляет никакие данные.
